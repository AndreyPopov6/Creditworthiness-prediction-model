# Creditworthiness-prediction-model

Модель прогнозирования кредитоспособности заёмщиков на языке **R**. Проект демонстрирует построение и визуализацию модели машинного обучения (дерево решений) на основе исторических данных о выдаче банковских кредитов.

## О проекте

Цель проекта — предсказать, является ли заёмщик кредитоспособным, используя алгоритм дерева решений. Проект включает полный цикл анализа: загрузку данных, построение модели, оценку её качества и визуализацию структуры дерева.

## Структура репозитория

| Файл | Описание |
|------|----------|
| `main.R` | Основной скрипт с кодом построения и оценки модели |
| `Bank_Loan_Granting.csv` | Набор данных с информацией о заявках на кредит |
| `decision_tree.png` | Визуализация построенного дерева решений |
| `size_of_tree.png` | График, иллюстрирующий размер/сложность дерева |
| `project.Rproj` | Файл проекта RStudio |
| `.gitignore` | Исключения для Git |

## Требования

- R (версия 4.0+)
- RStudio (рекомендуется, но не обязательно)
- Необходимые R-пакеты (устанавливаются из скрипта `main.R`): `rpart`, `rpart.plot`, `caret` и другие

## Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Studenkir/Creditworthiness-prediction-model.git
   ```
2. Откройте проект в RStudio (файл `project.Rproj`) или рабочую директорию с файлами.
3. Запустите скрипт `main.R` — он загрузит данные, обучит модель и сохранит визуализации.

## Данные

Файл `Bank_Loan_Granting.csv` содержит исторические записи о заявителях на кредит (признаки заёмщика и целевая переменная — одобрение/отказ).

## Визуализация

- `decision_tree.png` — итоговое дерево решений с правилами разбиения.
- `size_of_tree.png` — зависимость ошибки модели от сложности дерева (помогает выбрать оптимальную глубину).
